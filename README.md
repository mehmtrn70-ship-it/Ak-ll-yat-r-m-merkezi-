# Akıllı Yatırım Merkezi

Telefonda kişisel kullanım için geliştirilen, Google Play yayını hedefleyen bağımsız Android yatırım analiz uygulaması.

## İlk sürüm kapsamı
- Mobil ana ekran ve modül menüsü
- Fırsat analizi için başlangıç arayüzü
- Alım/hedef/zarar durdurma senaryosu hesaplayıcısı
- Sermaye ve getiri simülatörü
- İzleme listesi için temel altyapı
- Canlı veri entegrasyonu sonraki aşamada; veri yokken sahte canlı fiyat gösterilmez

## Durum
İlk temel Android iskeleti hazırlanıyor. Henüz yayınlanmış bir uygulama değildir. Piyasa verileri yatırım tavsiyesi veya getiri garantisi olarak sunulmayacaktır.

## APK oluşturma
GitHub Actions iş akışı eklendikten sonra Actions sekmesinden Android APK derlemesi çalıştırılabilir.
